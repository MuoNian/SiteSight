# 鹭见 SiteSight

> 消费级无人机航拍照片 → 一键三维场地模型 + AI 场地分析报告

鹭见 SiteSight 是面向建筑学学生的场地调研工具：用大疆 Lito X1 这类消费级无人机拍摄的普通 JPG 照片（含 GPS），上传后自动生成三维纹理模型、正射影像、DSM、点云，并产出建筑学视角的 AI 场地分析报告。全程本地处理，数据不上云。

“鹭见”取意鹭鸟俯瞰水面觅食——无人机俯瞰场地，看见真实地形，辅助设计决策。

---

## 一、它解决什么问题

建筑/规划专业做场地调研（基地分析）时，传统流程依赖：

- 专业测绘设备与资质（RTK、全站仪）
- 昂贵商业软件（大疆智图、Pix4D 等）
- 手工量算与反复踏勘

周期长、门槛高、单次成本高，学生和中小团队很难负担。而消费级无人机已经能拍出带 GPS 的高清航拍照片，**从照片到“可用的场地分析”之间，缺一个零门槛的自动工具**——这就是鹭见 SiteSight 要打的补丁。

## 二、核心功能

| 功能 | 说明 |
|---|---|
| 一键建模 | 拖入/粘贴照片路径 → 自动跑通三维模型、正射、DSM、点云、处理报告 |
| 快速模式 | 低精度粗模，10–20 张照片约 3–5 分钟出结果，适合演示 |
| AI 场地分析报告 | 自动读取建模元数据，生成面积、高差、坡度、建设适宜性等中文简报 |
| 反馈记忆 Agent | 记住你对报告风格的偏好，下次自动参考（赛道 4 核心模块） |
| 多格式导出 | OBJ / STL（3D 打印）/ PLY / LAZ / 打包 ZIP；SKP 可由 SketchUp 导入 OBJ 另存 |
| 实时进度 | 阶段化进度条 + 滚动日志 + 正射影像预览 |

## 三、技术架构

```text
前端（HTML + JS）→ Python HTTP 服务（标准库，零依赖）
                      ├── OpenDroneMap CLI（开源三维重建引擎）
                      ├── AI 报告模块（大模型 API，失败自动降级为内置模板）
                      └── 反馈记忆 Agent（本地 JSON 记忆库）
```

- 后端：Python 3.13 标准库，无需 `pip install`
- 建模引擎：OpenDroneMap 3.6.1（AGPL-3.0 开源，本地命令行版）
- 大模型：OpenAI 兼容 Chat Completions API（支持多供应商自动切换）
- 前端：原生 HTML + JavaScript，单文件页面

## 四、快速开始（Windows）

### 1. 环境要求

- Windows 10/11
- Python 3.13（仅标准库）
- OpenDroneMap 3.6.1 命令行版（安装到纯英文目录更稳妥，本项目已修复中文路径编码问题）
- 含 GPS 信息的无人机 JPG 照片（如大疆 Lito X1 48MP 照片）

### 2. 配置 ODM 路径

默认指向 `D:\WebODM（OpenDroneMap）\ODM`。若不同，编辑 `app/server.py` 顶部，或设置环境变量：

```cmd
set SITESIGHT_ODMDIR=C:\你的ODM目录
```

### 3. 启动网页版

双击 `scripts\启动鹭见SiteSight.bat`，浏览器自动打开 `http://127.0.0.1:8765`。

### 4. （可选）接入大模型

未配置时，AI 报告使用内置模板（离线可用）。配置后调用真实大模型生成更详细报告。

方式一（环境变量）：

```cmd
set LLM_API_KEY=你的key
set LLM_BASE_URL=https://api.openai.com/v1
set LLM_MODEL=gpt-4o-mini
```

方式二（配置文件，支持多供应商自动切换）：

复制 `app/config.example.json` 为 `app/config.json`，填入各供应商信息。`config.json` 已被 `.gitignore` 排除，**不会进入代码仓库**。

## 五、使用流程

1. 拍好照片（航向重叠 70–80%，旁向重叠 60–70%，保留 GPS EXIF）
2. 打开鹭见 SiteSight，粘贴照片文件夹路径或拖入照片
3. 勾选“生成 DSM”（测绘分析推荐），点“开始处理”
4. 等待进度完成，下载 OBJ/正射/DSM/点云，或一键导出 STL
5. 查看 AI 场地分析报告；给出反馈（如“以后突出坡度分析”），系统会记住并在下次生成时参考

已有 ODM 成果时，可在“打开已有成果”里粘贴成果文件夹路径直接加载，跳过建模、秒出 AI 报告（适合演示）。
