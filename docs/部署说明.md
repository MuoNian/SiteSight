# 鹭见 SiteSight 部署说明

## 一、本地部署（推荐，用于开发与演示）

### 1. 环境准备

- Windows 10/11
- Python 3.13（仅标准库，无需 pip install）
- OpenDroneMap 3.6.1 命令行版（已修复中文路径编码）

### 2. 配置 ODM 路径

默认 `app/server.py` / `app/site_report.py` 中的 ODM 路径为：

```python
r"D:\WebODM（OpenDroneMap）\ODM"
```

若不同，设置环境变量：

```cmd
set SITESIGHT_ODMDIR=C:\你的ODM目录
```

### 3. 启动

双击 `scripts\启动鹭见SiteSight.bat`，浏览器打开 `http://127.0.0.1:8765`。

### 4. 环境变量

| 变量 | 说明 | 默认值 |
|---|---|---|
| `SITESIGHT_ODMDIR` | ODM 安装目录 | `D:\WebODM（OpenDroneMap）\ODM` |
| `SITESIGHT_PROJROOT` | 成果根目录 | `~\Desktop\SiteSight_Results` |
| `SITESIGHT_PORT` | 服务端口 | `8765` |
| `SITESIGHT_NO_BROWSER` | 禁止自动打开浏览器 | `0` |
| `SITESIGHT_MEMORY` | 记忆库路径 | `~\SiteSight\memory.json` |
| `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL` | 大模型配置（可选） | 无 |

## 二、大模型 API 配置（可选）

复制 `app/config.example.json` 为 `app/config.json`，填入供应商信息（支持多个，自动切换）：

```json
{
  "providers": [
    {
      "name": "我的供应商",
      "base_url": "https://api.example.com/v1",
      "api_key": "sk-xxx",
      "model": "my-model"
    }
  ]
}
```

> `app/config.json` 已被 `.gitignore` 排除，严禁提交到仓库。

## 三、云服务器部署（公网演示站，赛期后可选）

### 方案 A：海外服务器（免备案）

1. 租 8 核 32G 以上海外云服务器（新加坡/香港节点）
2. 安装 Docker，部署 WebODM：
   ```bash
   git clone https://github.com/OpenDroneMap/WebODM.git
   cd WebODM
   docker compose up -d --build
   ```
3. 将本项目的网页版部署到同一服务器或另一台轻量服务器，通过反向代理整合

### 方案 B：国内服务器 + 备案

1. 阿里云/腾讯云 8 核 32G 以上，选 Ubuntu
2. 完成 ICP 备案（约 7–15 个工作日）
3. 同上部署

### 注意事项

- 照片处理非常消耗 CPU/内存，建议至少 8 核 32G；60 张照片任务约占 5–15 GB 磁盘
- 大文件上传/下载建议接入对象存储（如七牛云 Kodo），这也是赛道 4 生态的加分点
- 生产环境必须配置 HTTPS 与访问控制，防止 ODM 接口被滥用

## 四、常见问题

**Q：ODM 报 UnicodeDecodeError / 中文路径问题？**
A：本项目已做修复；若重装 ODM，请安装到纯英文路径，成果目录固定用英文名。

**Q：AI 报告一直是模板版本？**
A：检查 `app/config.json` 或环境变量是否正确配置；未配置时自动使用内置模板（离线可用）。

**Q：如何导出 SKP / 3DM？**
A：先用网页导出 OBJ/STL，再用 SketchUp 导入 OBJ 另存 SKP，或用 Rhino 导入 OBJ 另存 3DM。

**Q：快速模式效果如何？**
A：降低点云密度与网格精度，适合演示；正式成果建议关闭快速模式。
