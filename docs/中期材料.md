## 一、项目定义（摘要）

- 项目名称：鹭见 SiteSight
- 目标用户：建筑学/城乡规划专业学生（本人即为第一个用户）
- 核心问题：场地调研依赖昂贵测绘软件、门槛高、周期长，而消费级无人机照片与“可用场地分析”之间缺少零门槛工具
- 解决方案：无人机照片 → 自动三维重建（OpenDroneMap）→ 模型/正射/DSM/点云 → AI 场地分析报告 → 多格式导出
- 差异化：专业结构化 AI 报告 + 反馈记忆 Agent（越用越懂用户）
- 参赛：主投奇绩创坛赛道，双投七牛云赛道（反馈记忆 Agent 即赛道 4 核心）
