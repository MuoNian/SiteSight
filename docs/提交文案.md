## 作品名称 *

鹭见 SiteSight —— 航拍照片一键三维建模与 AI 场地分析平台

## 所属赛道 *

奇绩创坛赛道「为现实打个补丁」（主投）；同时报名七牛云赛道「开发一个具备反馈记忆能力的轻量 Agent 系统」（双投）。

## 一句话介绍 *

消费级无人机照片一键生成三维场地模型和 AI 场地分析报告，让场地调研不再依赖昂贵测绘软件。

## 作品简介

鹭见 SiteSight 面向建筑学与城乡规划专业学生，用大疆 Lito X1 等消费级无人机拍摄的含 GPS 照片，自动完成三维重建，产出三维纹理模型（OBJ/STL）、正射影像、DSM、点云，并基于建模数据生成建筑学视角的 AI 场地分析报告（面积、高差、坡度、建设适宜性）。系统内置反馈记忆 Agent：用户对报告提出偏好后，系统沉淀记忆并在后续生成中自动参考，让分析结果越来越贴合个人工作习惯。全程本地处理，数据不上云；未配置大模型时自动降级为内置模板，保证离线可用。项目基于开源 OpenDroneMap 构建，后端仅用 Python 标准库，已用 60 张真实航拍照片完成全流程验证。

## 项目背景 *

建筑/规划专业做场地调研时，需要了解场地的面积、高差、地形与现状，但传统流程依赖专业测绘设备、昂贵商业软件（大疆智图、Pix4D）和较长的学习周期。学生群体普遍没有预算和精力使用这些工具，导致课程设计与竞赛中的基地分析停留在“看地图、猜地形”。与此同时，消费级无人机已经普及，随手拍摄的带 GPS 照片背后，缺的正是一个“零门槛的照片→场地分析”自动工具。

## 解决的问题 *

1. 场地调研成本高：用数百元的无人机替代数万元的测绘软件核心环节。
2. 操作门槛高：把空三、点云、GIS 等复杂流程封装为“拖照片即用”。
3. 周期长：把数天的踏勘量算压缩到“拍照 + 一小时”。
4. 成果割裂：一次处理同时产出模型、影像、DSM、点云与文字报告，形成完整基地资料包。

## 核心功能 *

1. 一键三维建模：上传/拖入含 GPS 的 JPG 照片，自动产出 OBJ 纹理模型、正射影像、DSM、点云与处理报告。
2. AI 场地分析报告：自动读取建模元数据，按“场地概况→地形特征→建设适宜性→下一步建议”生成中文简报。
3. 反馈记忆 Agent：记录用户对报告风格的偏好，后续生成自动检索并参考（赛道 4 核心）。
4. 多格式导出：OBJ / STL（3D 打印）/ PLY / LAZ / 打包 ZIP；SKP、3DM 可经 Rhino/SketchUp 转换。
5. 实时进度与本地隐私：阶段进度条 + 日志，全程本机处理。

## 技术方案 *

- 三维重建：OpenDroneMap 3.6.1 开源引擎（本地 CLI），已修复 Windows 中文路径编码问题
- 后端：Python 3.13 标准库 HTTP 服务，零第三方依赖
- AI 报告：OpenAI 兼容 Chat Completions API，支持多供应商自动切换（Stepfun / 七牛云 / 奇绩创坛额度），失败自动降级内置模板
- 记忆 Agent：本地 JSON 记忆库 + 主题关键词检索 + 使用频次排序，纯 Python 实现
- 前端：原生 HTML + JavaScript 单页应用

## 创新点 *

1. 零门槛：专业级三维重建压缩为“拖照片→出结果”，建筑生 5 分钟上手。
2. 专业结构化 AI 报告：按建筑场地分析流程输出，而非通用聊天。
3. 反馈记忆闭环：报告越用越懂用户偏好，形成个人化场地分析工作流。
4. 低成本替代：消费级无人机 + 开源引擎 + 赛方 Token 额度，覆盖专业软件核心环节。

## 应用价值 *

学生与小型团队可用极低成本完成场地数字化与前期分析，服务于课程设计、竞赛、乡村建设、社区更新等场景；反馈记忆机制可推广到任何重复性文档生成任务，具备独立产品化潜力。

## 使用说明 *

1. 环境：Windows 10/11 + Python 3.13 + OpenDroneMap 3.6.1（安装目录可配置）
2. 启动：双击 `scripts\启动鹭见SiteSight.bat`，浏览器自动打开 http://127.0.0.1:8765
3. 使用：粘贴照片文件夹路径（或拖入照片）→ 勾选 DSM/快速模式 → 开始处理 → 等待完成 → 下载成果 / 导出 STL / 查看 AI 报告
4. 反馈：在“告诉我你的偏好”输入框写下报告偏好，系统自动记住并在下次生成时参考
5. 离线可用：未配置大模型 API 时，AI 报告自动使用内置模板
