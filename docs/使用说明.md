# 鹭见 SiteSight 使用说明

一个完全在本机运行的“网页版”三维建模与场地分析工具：浏览器里选照片 → 开始处理 → 实时看进度 → 下载成果 + AI 场地分析报告 + 反馈偏好。数据不会上传到任何服务器。

## 一、启动

1. 双击 `scripts\启动鹭见SiteSight.bat`
2. 浏览器自动打开页面（http://127.0.0.1:8765）；没打开就手动输入
3. 黑色窗口是服务端，处理期间不要关；关闭 = 停止服务（已生成成果不受影响）

## 二、使用流程

### 1. 选照片（二选一）

- 方式一（推荐）：粘贴照片文件夹路径，点“使用此路径”
- 方式二：把照片或整个文件夹拖到虚线框（或点击选择）

### 0. 打开已有成果（跳过建模）

如果只想对已生成的 ODM 成果做分析（不重新建模），在“打开已有成果”里粘贴成果文件夹路径，点“加载成果”，即可直接下载成果、生成 AI 报告——适合演示场景。

### 2. 处理选项

- 生成 DSM：推荐勾选（测绘/地形分析用）
- 快速模式：勾选后降低精度、加快速度（适合演示）

### 3. 开始处理

页面实时显示当前阶段、进度条和日志。处理时间与照片数量和电脑性能有关（60 张照片约 16 分钟）。

### 4. 成果下载

- 逐个下载 OBJ / 正射影像 / DSM / 点云 / 报告
- 打包下载全部（ZIP）
- 导出 STL（3D 打印/模型）、PLY、LAZ
- 打开成果文件夹直接浏览

### 5. AI 场地分析报告

自动生成建筑学视角的场地简报：场地概况、地形特征、建设适宜性、下一步建议。

### 6. 反馈偏好（记忆 Agent）

在“告诉我你的偏好”里输入，例如：

- “以后报告要突出坡度分析”
- “面积数据放在最前面”
- “不要写水系相关内容”
- “报告要更简洁专业”

点“记住这条偏好”，下次生成报告时会自动参考；可随时删除。

## 三、快速演示模式

用 `scripts\快速生成三维模型.bat`（一键脚本 + --fast 参数），10–20 张照片约 3–5 分钟出粗模，适合路演。

## 四、成果保存在哪里

优先保存在 `D:\SiteSight_Results\project_日期_时间\`（数据盘空间大，避免 C 盘爆满）；没有 D/E 数据盘时才放桌面。ODM 不支持中文路径，固定用英文目录名。也可用环境变量 `SITESIGHT_PROJROOT` 指定位置。

> 一键脚本默认输出到 `D:\ODM_Results`；启动前会自动检查目标盘剩余空间，不足 20GB 会提前停止，避免处理到一半磁盘写满。

## 五、常见问题

- **提示“没有 JPG 照片”**：确认路径正确；DNG（RAW）不参与处理
- **处理失败**：看页面日志或成果目录里的 processing.log；常见原因是照片模糊、重叠率不够（航向 70–80%、旁向 60–70%）
- **上传慢**：照片多时用“方式一”粘贴路径，秒级复制
- **端口被占用**：关掉已开的网页版再重新双击
- **换电脑/ODM 路径变了**：设置环境变量 `SITESIGHT_ODMDIR` 指向新的 ODM 目录
- **SKP / 3DM**：网页导出 OBJ/STL 后，用 SketchUp / Rhino 导入转换
