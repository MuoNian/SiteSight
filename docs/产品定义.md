# 鹭见 SiteSight · 产品定义

> 版本：v1.0（2026-08-20，赛期内第一版）

## 一句话介绍

消费级无人机照片一键生成三维场地模型和 AI 场地分析报告，让场地调研不再依赖昂贵的测绘软件。

## 目标用户与场景（第一版聚焦）

**核心用户：建筑学/城乡规划专业学生。**

典型场景：课程设计、毕业设计、竞赛方案前期的“基地调研 / 场地分析”——需要了解场地的面积、高差、地形起伏、现状建筑与建设适宜性，并以此为依据展开设计。学生没有预算购买大疆智图、Pix4D 等专业软件，也没有测绘资质和设备，但普遍可以借到/买到一台消费级无人机。

后续扩展人群（第二期再考虑）：规划师、景观设计师、乡村建设团队、小型测绘工作室、房地产前期策划、科普教育等。

## 用户痛点

1. **成本高**：专业测绘软件年费数千到数万元，学生难以负担。
2. **门槛高**：需要学习空三、点云、GIS 等复杂操作，建筑生精力有限。
3. **周期长**：传统踏勘 + 手工量算 + 画分析图，一个基地要耗数天。
4. **成果割裂**：照片、模型、分析图分散在不同软件里，难以形成完整的“基地资料包”。

## 解决方案（一次完整工作流）

```text
大疆 Lito X1 航拍（含 GPS 的 JPG）
        ↓
鹭见 SiteSight 网页（拖入照片 / 粘贴路径）
        ↓
自动三维重建（OpenDroneMap）
        ↓
三维纹理模型 OBJ + 正射影像 + DSM + 点云 + 处理报告
        ↓
AI 场地分析报告（面积 / 高差 / 坡度 / 建设适宜性）
        ↓
导出 STL / OBJ / PLY / LAZ → 导入 Rhino / SketchUp / 3D 打印
```

## 核心功能

1. **一键建模**：本地网页，拖照片即用；实时进度与日志。
2. **多成果产出**：OBJ 三维模型、正射影像 GeoTIFF、DSM、LAZ/PLY 点云、PDF 报告。
3. **AI 场地分析报告**：读取建模元数据，用大模型生成建筑学视角的中文简报；未联网时用内置模板兜底。
4. **反馈记忆 Agent**：用户反馈报告偏好（如“突出坡度”“不要写水文”），系统沉淀记忆，后续生成自动参考——既服务本产品，也是赛道 4 的核心技术。
5. **多格式导出**：OBJ / STL（3D 打印）/ PLY / LAZ / ZIP 打包；SKP、3DM 由 Rhino/SketchUp 导入 OBJ 后转换。
6. **本地隐私**：全程本机处理，照片与成果不上云。

## 技术方案

- 后端：Python 3.13 标准库 HTTP 服务（零第三方依赖，部署简单）
- 三维重建：OpenDroneMap 3.6.1 开源引擎（本地 CLI，已修复 Windows 中文路径编码问题）
- AI 报告：OpenAI 兼容 Chat Completions API，支持多供应商自动切换（赛方提供 Stepfun / 七牛云 / 奇绩创坛额度），失败自动降级内置模板
- 记忆 Agent：纯 Python 本地 JSON 记忆库，主题关键词检索 + 使用频次排序
- 前端：原生 HTML + JavaScript 单页

## 创新点

1. **零门槛**：把专业级三维重建压缩成“拖照片 → 出结果”，建筑生 5 分钟上手。
2. **专业视角的 AI 报告**：不是通用 AI 聊天，而是按建筑场地分析流程（概况→地形→适宜性→建议）结构化输出。
3. **反馈记忆**：报告会越用越懂你的偏好，形成个人化工作流（赛道 4 的落地应用）。
4. **低成本闭环**：学生买得起的无人机 + 开源引擎 + 赛方 Token 额度，替代万元级专业软件的核心环节。

## 应用价值

- 对个人：把场地调研从“数天”压缩到“拍照 + 一小时”，产出可直接用于课程设计与竞赛。
- 对行业：降低场地数字化门槛，让更多小团队能做前期分析，减少拍脑袋决策。
- 对社会：助力乡村建设、社区更新、灾害评估等轻量化测绘需求。
