# 鹭见 SiteSight 演示视频脚本

## 视频规格

- 时长：60–90 秒
- 分辨率：1920×1080（横屏）
- 出镜：口播 + 屏幕录制（出镜可选）
- 风格：真实使用，无造假

## 分镜脚本

| 时间 | 画面 | 旁白 / 字幕 |
|---|---|---|
| 0:00–0:08 | 手持大疆 Lito X1 无人机起飞，拍摄地面画面（或展示已有航拍素材） | “这是一块待分析的城市空地。传统场地分析需要专业测绘，成本高、周期长。” |
| 0:08–0:15 | 切到电脑：双击“启动鹭见SiteSight.bat”，浏览器打开 | “用鹭见 SiteSight，消费级无人机拍的照片就能一键出模型、出分析报告。” |
| 0:15–0:30 | 拖入 60 张照片文件夹 → 勾选快速模式 → 开始处理 → 展示实时进度条和日志 | “选择照片、勾选模式、开始处理。全程本地运行，数据不上云。” |
| 0:30–0:45 | 处理完成 → 展示三维模型预览、正射影像、DSM → 点开 AI 报告 | “处理完成后，自动生成三维模型、正射影像、DSM，还有 AI 场地分析报告。” |
| 0:45–0:60 | 展示报告内容（面积、高差、坡度、建设建议）→ 输入反馈“以后突出坡度分析” | “报告按建筑学流程结构化输出。不满意？告诉它你的偏好。” |
| 0:60–0:75 | 重新生成报告 → 展示坡度分析被突出 → 导出 STL → SketchUp 打开 | “记忆 Agent 会记住你的偏好，下次自动参考。还能导出 STL 直接进设计软件。” |
| 0:75–0:90 | 产品 logo + 赛道信息 | “鹭见 SiteSight —— 为现实打个补丁。大工黑客松 2026。” |

## 录制建议

- 真实数据优先：用已有 60 张照片成果做预录制
- 实时跑不动就提前用快速模式生成小成果，录制时直接展示
- 字幕必备；旁白用手机录音或录屏软件配音
