# 鹭见 SiteSight · 中期指导材料（2026-08-27 晚）

## 一、项目定义（30 秒版）

- **项目名称**：鹭见 SiteSight —— 航拍照片一键三维建模与 AI 场地分析平台
- **一句话介绍**：消费级无人机照片一键生成三维场地模型和 AI 场地分析报告，让场地调研不再依赖昂贵测绘软件。
- **参赛赛道**：奇绩创坛「为现实打个补丁」（主投）；七牛云「反馈记忆 Agent」（双投）
- **目标用户**：建筑学/城乡规划专业学生做课程设计、竞赛、毕设的场地调研；本人就是第一个用户
- **核心机制**：照片进 →（OpenDroneMap 重建）→ 模型/正射/DSM/点云 →（AI 报告 + 反馈记忆）→ 设计底图

## 二、解决什么问题

传统场地调研依赖大疆智图 / Pix4D 等昂贵专业软件和测绘设备，学生用不起、学不会、等不起。消费级无人机已普及，缺的是“照片到可用场地分析”的零门槛工具。

## 五、想请教的问题（按优先级）

1. **精度与时间的取舍**：大场景高精度 3D 建模跑了 10+ 小时，评委更看重“完成度+演示效果”还是“算法/工程深度”？怎么把“照片密度→精度→成本”的量化关系讲成加分项而不是减分项？
2. **远景照片问题**：无人机补拍的镜头朝上照片会撑大重建范围，我们目前用“云台俯仰角筛选”解决；有没有更聪明的自动方案（如按重建匹配数自动剔除离群照片）值得做？
3. **双投策略**：主投奇绩创坛、双投七牛云，现场演示时“产品故事”和“记忆 Agent 技术”怎么分配时间最有效？
4. **在线演示**：Cloud Studio 公网链接在工作空间休眠后会失效，评审期保持在线的最佳实践？
5. **用户验证**：如果 8/28–8/29 只找到 1 名同学测试，怎么让“真实用户验证”在材料里最有说服力？
