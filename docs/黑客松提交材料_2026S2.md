### 作品名称

鹭见 SiteSight

### 所属赛道

### 一句话介绍

消费级无人机照片一键生成三维场地模型与 AI 场地分析报告的开源免费桌面软件。

### 作品简介

鹭见 SiteSight 是面向建筑学、城乡规划学生的场地调研工具：使用大疆 NEO 这类消费级无人机拍摄的普通 JPG 照片（含 GPS 信息），上传后自动完成空三、稠密点云、网格与纹理贴图，生成三维模型、正射影像、DSM、点云等成果，并产出建筑学视角的 AI 场地分析报告；报告会记住用户偏好，越用越懂用户。全程本地处理，数据不出电脑。

“鹭见”取意鹭鸟俯瞰水面觅食——无人机俯瞰场地，看见真实地形，辅助设计决策。

### 项目详情

传统场地测绘依赖专业测绘设备与资质、昂贵商业软件（大疆智图、Pix4D 等），周期长、门槛高、单次成本高，学生和中小团队难以负担。与此同时，消费级无人机已经能拍出带 GPS 的高清航拍照片——从照片到“可用的场地分析”之间，缺一个零门槛的自动工具。

本项目把这个缺口补上：用开源三维重建引擎 OpenDroneMap 做本地重建，用结构化提示词让大模型输出建筑场地分析报告，再用反馈记忆机制让报告越用越贴合个人偏好。产品以桌面安装包形式分发，内置建模引擎、开箱即用，并同步提供真实航拍测试素材，任何人都能下载体验完整流程。

### 项目背景

- 建筑/规划专业做课程设计、竞赛、毕业设计时，都需要“基地调研 / 场地分析”（面积、高差、坡度、现状与建设适宜性）。
- 专业方案（RTK/全站仪 + 大疆智图/Pix4D）成本数万元、需要培训，学生群体基本不可及。
- 消费级无人机普及（千元级）但缺少配套的零门槛分析工具。
- 开源生态（OpenDroneMap）已具备重建能力，但使用门槛高，普通学生无法直接使用。

### 解决的问题

1. **成本问题**：把数万元的硬件 + 软件投入，压缩到千元级无人机 + 免费开源软件。
2. **门槛问题**：把“空三、点云、网格、正射、DSM、报告”这一整套专业流程封装为“拖入照片 → 一键完成”。
3. **效率问题**：传统人工量算与反复踏勘耗时长，本工具分钟级出成果。
4. **个性化问题**：通用 AI 聊天不懂场地分析流程；本项目按建筑场地分析结构生成报告，并记住用户偏好。

### 核心功能

| 功能 | 说明 |
|---|---|
| 一键三维建模 | 拖入/选择照片文件夹，自动完成空三、稠密点云、网格与纹理贴图 |
| 三档精度 | 快速 / 标准 / 高精度，快速模式几分钟出粗模，适合现场演示 |
| AI 场地分析报告 | 自动解读坡度、高差、面积、建设适宜性等，输出中文简报 |
| 反馈记忆 Agent | 记住报告风格偏好，后续报告自动参考（赛道 4 核心） |
| 成果管理 | 用系统默认软件打开；本地导出 STL / PLY / LAZ / 打包 ZIP |
| 实时日志 | 进度条、已用时长、剩余时间估算、错误原因中文诊断 |
| 中英双语安装 | 安装向导支持简体中文 / English |

### 技术方案

```text
桌面外壳（pywebview）→ 本地网页前端（原生 HTML/JS）
                        → Python HTTP 服务（仅标准库）
                            ├── OpenDroneMap CLI（开源三维重建引擎，AGPL-3.0）
                            ├── AI 报告模块（OpenAI 兼容 API，失败自动降级为内置模板）
                            └── 反馈记忆 Agent（本地 JSON 记忆库）
```

- 后端：Python 3.13 标准库，零第三方依赖。
- 建模引擎：OpenDroneMap 3.6.1，本地命令行版，随安装包分发。
- 大模型：OpenAI 兼容 Chat Completions API，支持多供应商自动切换；未配置 API 时使用内置离线模板。
- 前端：原生 HTML + JavaScript，无第三方前端库。
- 打包分发：PyInstaller + Inno Setup，安装包自包含建模引擎（约 1 GB），中英双语安装向导。

### 创新点

1. **零门槛全自动闭环**：消费级无人机 + 免费开源软件，从照片到可用的场地分析一键完成。
2. **建筑学视角的结构化 AI 报告**：按场地分析流程生成报告，而非通用聊天；失败自动降级离线模板，保证可用性。
3. **反馈记忆 Agent**：报告偏好沉淀为本地记忆，重复性任务越用越贴合个人习惯（赛道 4 核心）。
4. **极致的成本优势**：硬件约 1,000 元（DJI NEO）对比专业测绘无人机约 16,000 元；软件 0 元对比专业软件买断数万元。
5. **本地优先 + 隐私安全**：数据不出电脑，不依赖云端；安装包开箱即用，无需配置环境。
6. **可复现的真实验证**：60 张真实航拍照片端到端跑通（正射 6749×6245、GSD 0.05 m、高差 92.4 m、约 10.54 公顷），STL 导出实测 44.9 MB。

### 应用价值

- **教育场景**：建筑/规划专业学生用千元无人机即可完成课程设计、竞赛、毕业设计的基地调研。
- **小微团队与乡村建设**：低成本完成场地现状记录、地形分析、建设适宜性初判。
- **设计工作流衔接**：OBJ/STL 可进入 Rhino / SketchUp / 3D 打印；正射/DSM 可作为测绘底图。
- **开源生态**：基于 OpenDroneMap 构建，反哺开源社区，可二次开发。

### 使用说明

1. **下载安装**：从 GitHub Releases 下载安装包（约 1 GB，含建模引擎），以管理员身份安装；首次运行若出现 SmartScreen 提示，点“更多信息 → 仍要运行”。
2. **准备照片**：无人机环绕拍摄，照片集中放在一个文件夹，确保含 GPS 信息（右键属性可查）；不想自己拍可下载测试素材包。
3. **启动建模**：打开软件 → 「启动程序」→ 选择照片文件夹 → 选择精度（快速/标准/高精度）→ 点击“开始建模”。
4. **查看进度**：「日志」页实时显示阶段、进度条、已用时长与剩余时间估算；出错时会给出中文原因与建议。
5. **查看成果**：「成果」页打开文件夹、用系统默认软件查看文件，或导出 STL / PLY / LAZ / 打包 ZIP。
6. **AI 报告（可选）**：在「设置 → 外部 API 接入」填写 OpenAI 兼容 API 后，成果页可生成 AI 分析报告；不配置则使用内置离线模板。
